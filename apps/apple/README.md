# Apple app workspace

Create the initial Xcode project here with two application targets:

- `MannerPath` — iOS 18+
- `MannerPathWatch` — watchOS 11+

Use SwiftUI lifecycle and Swift 6 language mode.

Keep the Xcode project generated by Xcode under version control. Prefer synchronized source folders to reduce `project.pbxproj` churn.

Initial capabilities should be minimal. Add location usage descriptions only when Core Location is introduced. Do not add Always Location capability.
