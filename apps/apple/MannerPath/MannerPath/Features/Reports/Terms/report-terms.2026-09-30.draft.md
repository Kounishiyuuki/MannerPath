# MannerPath 利用者報告に関する規約（草案）

> **DRAFT — requires legal/maintainer approval before production.**
> この文書は技術要件を整理した草案であり、法的に確認された利用規約ではありません。
> 本番公開・コミュニティ由来データの公開は、法務またはメンテナーの承認まで行いません（Issue #124）。

- 版 (terms version): `report-terms.2026-09-30.draft`
- 対象: MannerPath アプリの「情報を報告」機能で送信される報告
- 状態: 草案。この版への同意は記録されますが、この版は**公開の根拠になりません**（`publication_rights = pending`）。

## 1. 報告として送信される情報

報告には、報告の種類、対象スポット、地図上で指定した位置（新しいスポット・移転の報告のみ）、
確認日（日単位、任意）、任意のメモ、同意した規約の版が含まれます。
アカウントは不要です。端末の現在地、位置の履歴、氏名、連絡先は送信されません。
不正利用対策として、端末ごとのランダムな識別子からサーバー側で計算した非可逆な値を使います。

## 2. MannerPath による保存と処理

MannerPath は、報告を保存し、内容を確認し（モデレーション）、既存のデータや他の報告と照合するために処理します。
個人に結び付き得る内容（メモ、指定位置、確認日、不正利用対策の値）は受信から 90 日以内に削除します（ADR-0007）。

## 3. 掲載は即時ではありません

報告はすぐには地図に掲載されません。モデレーターが確認し、複数の独立した報告や他の情報源と照合したうえで、
審査を経たものだけがデータの根拠になります。報告が採用されない場合もあります。

## 4. 審査済みの情報の再利用と再配布

この版の規約が承認された後は、審査を経た報告から作られた**加工済みの情報**
（採用された位置、スポットの存在・状態に関する確認、審査の結果）を、MannerPath のデータとして
保存・公開し、アプリ、API、地図タイル、データの配布物を通じて再配布できることに同意していただきます。
公開される情報は「利用者報告（審査済み）」として公式情報と区別して表示されます。

## 5. 公開に含めない情報

メモ、確認日、送信日時、不正利用対策の値、端末の識別子など、個人を特定し得る情報や
報告者と結び付く情報は、公開データ（アプリ、API、地図タイル、データの配布物）に含めません。
報告 ID は、審査結果の根拠を追跡するための内部記録（MannerPath のデータベース間の移行を含む）にだけ残り、
公開データには含まれません。

## 6. 同意の記録

報告を送信する前に、アプリでこの規約を表示し、明示的な同意を求めます。
報告には同意した版が記録され、App Attest による署名の対象にも含まれます。
この仕組みの導入前に送信された報告や、同意のない報告は、公開の根拠として扱いません。
新しい版は過去の報告に遡って適用しません。
